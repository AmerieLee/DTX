# What is HTML?

**HTML (HyperText Markup Language)** is the standard language used to create web pages.

---

# Basic HTML Structure

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
</head>
<body>

</body>
</html>
```

---

# Common Tags

- `<html>`
- `<head>`
- `<title>`
- `<body>`
- `<h1>`
- `<p>`

---

# Lists

```html
<ul>
  <li>Apple</li>
  <li>Banana</li>
</ul>
```

---

# Activity

Create a web page with:
- One heading
- Two paragraphs
- One unordered list

---

# Summary

HTML uses tags to organise and display web page content.
