# What is CSS?
CSS controls the appearance of web pages.

---

# Linking CSS
```html
<link rel="stylesheet" href="style.css">
```

---

# Example CSS
```css
body{
  background:#f5f5f5;
  font-family:Arial;
}
h1{
  color:navy;
}
```
