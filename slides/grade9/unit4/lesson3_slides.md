# Unit 4
## Lesson 3: Images and Hyperlinks

---

# Learning Objectives

- Insert images
- Create hyperlinks
- Understand file paths
- Build navigation

---

# Images

```html
<img src="images/photo.jpg" alt="Photo" width="300">
```

---

# Image Attributes

- src
- alt
- width
- height

---

# Hyperlinks

```html
<a href="about.html">About</a>
```

External:

```html
<a href="https://www.wikipedia.org">Wikipedia</a>
```

---

# Relative vs Absolute Paths

Relative:
- about.html
- images/logo.png

Absolute:
- https://example.com/about.html

---

# Navigation Menu

```html
<nav>
<a href="index.html">Home</a>
<a href="about.html">About</a>
<a href="contact.html">Contact</a>
</nav>
```

---

# Activity

Build a two-page website with:
- One image
- Three links

---

# Summary

Images improve appearance.
Hyperlinks connect pages.
Navigation helps users move around a website.
