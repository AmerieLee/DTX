# Slide 3 – What Are Productivity Tools?

Productivity tools are software applications that help people create, organise, analyse, communicate, and collaborate more effectively.

Examples include:

- Word Processors
- Spreadsheets
- Presentation Software
- Database Software
- Collaboration Tools

---

# Slide 4 – Common Productivity Applications

| Category | Purpose |
|-----------|---------|
| Word Processor | Create documents |
| Spreadsheet | Perform calculations |
| Presentation | Create slides |
| Database | Store and organise data |
| Collaboration | Share and work together |
