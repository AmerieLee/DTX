# Lesson 3 – Images and Hyperlinks

## Learning Objectives
- Insert images into a web page.
- Create hyperlinks between web pages.
- Understand relative and absolute paths.
- Build a simple navigation menu.

## Success Criteria
- I can add an image using the `<img>` tag.
- I can create links using the `<a>` tag.
- I can explain the difference between relative and absolute paths.

## Adding Images

```html
<img src="images/school.jpg" alt="School" width="300">
```

### Image Attributes
- `src` – image location
- `alt` – alternative text
- `width` / `height` – image size

## Creating Hyperlinks

```html
<a href="about.html">About Me</a>
```

External link:

```html
<a href="https://www.wikipedia.org">Wikipedia</a>
```

## Relative vs Absolute Paths

| Relative | Absolute |
|----------|----------|
| about.html | https://example.com/about.html |
| images/logo.png | https://example.com/images/logo.png |

## Navigation Menu

```html
<nav>
  <a href="index.html">Home</a> |
  <a href="about.html">About</a> |
  <a href="contact.html">Contact</a>
</nav>
```

## Activity
Create a two-page website with:
- One image
- Three navigation links

## Summary
Images make websites engaging, while hyperlinks connect pages and resources.

## Key Vocabulary
Image, Hyperlink, Anchor, Relative Path, Absolute Path, Navigation
