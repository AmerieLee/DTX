# Lesson 4 – CSS Basics

## Learning Objectives
- Understand CSS.
- Apply colours, fonts and spacing.
- Link a CSS file to HTML.

## What is CSS?
CSS (Cascading Style Sheets) controls the appearance of web pages.

## Linking CSS
```html
<link rel="stylesheet" href="style.css">
```

## Example
```css
body{
  font-family: Arial, sans-serif;
  background:#f5f5f5;
}
h1{color:navy;}
p{color:#333;}
```

## Common Properties
- color
- background-color
- font-size
- font-family
- margin
- padding

## Activity
Style your webpage using CSS.

## Summary
CSS improves the appearance and consistency of websites.
