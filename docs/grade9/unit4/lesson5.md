# Lesson 5 – Building a Complete Website

## Learning Objectives
- Combine HTML and CSS.
- Organise website files and folders.
- Build a multi-page website.
- Test and improve website usability.

## Project
Create a website with:
- Home, About and Contact pages
- Navigation menu
- Images
- External CSS stylesheet

## Suggested Structure
```
website/
├── index.html
├── about.html
├── contact.html
├── style.css
└── images/
```

## Checklist
- Consistent navigation
- Working links
- Images display correctly
- CSS applied to every page

## Reflection
How could you improve your website?

## Summary
A complete website combines structure (HTML), presentation (CSS), and good organisation.
