# Lesson 2 – Basic HTML

## Learning Objectives
- Understand HTML
- Create a simple web page

## Basic HTML
```html
<!DOCTYPE html>
<html>
<head><title>My Page</title></head>
<body>
<h1>Hello World!</h1>
<p>Welcome!</p>
</body>
</html>
```

## Common Tags
- html
- head
- body
- h1
- p
- ul
- ol
- li
