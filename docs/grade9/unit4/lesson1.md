# Lesson 1 – Introduction to the Web

## Learning Objectives
- Explain the difference between the Internet and the World Wide Web.
- Identify the roles of web browsers and web servers.
- Describe the structure of a URL.
- Understand how a web page is delivered.

## Success Criteria
- I can explain what the Internet is.
- I can explain what the Web is.
- I can identify parts of a URL.
- I can describe how a browser loads a web page.

## Warm-Up
Discuss:
1. Which websites do you visit most often?
2. How do you think a web page reaches your device?

## The Internet
The Internet is a global network of connected computers and devices that communicate using standard protocols.

## The World Wide Web
The World Wide Web (WWW) is a collection of web pages and websites that are accessed through the Internet.

## Internet vs Web
| Internet | World Wide Web |
|-----------|----------------|
| Physical network | Information system |
| Uses many services | Uses websites and web pages |
| Supports email, games, cloud storage | Uses HTTP/HTTPS |

## Web Browsers
Examples:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

A browser requests web pages from a web server and displays them.

## Web Servers
A web server stores website files and sends them to browsers when requested.

## URLs
Example:
https://www.example.com/index.html

Parts:
- Protocol
- Domain Name
- Path
- File Name

## Client–Server Model
1. User enters a URL.
2. Browser sends a request.
3. Server processes the request.
4. Server returns the web page.
5. Browser displays the page.

## Check Your Understanding
1. What is the Internet?
2. What is the World Wide Web?
3. Name two web browsers.
4. What does a web server do?
5. What is a URL?

## Summary
The Internet connects devices worldwide, while the World Wide Web provides websites accessed through browsers. Browsers communicate with web servers using URLs and web protocols.

## Key Vocabulary
Internet, World Wide Web, Browser, Web Server, URL, HTTP, HTTPS, Client, Server
