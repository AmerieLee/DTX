# Lesson 1 – Introduction to Productivity Tools

## Learning Objectives
- Define productivity tools.
- Identify common office applications.
- Explain how productivity software improves efficiency.

## Starter Activity
Discuss:
1. What software do you use to create documents?
2. Which tools help you collaborate?

## What Are Productivity Tools?
Productivity tools are software applications that help users create, edit, organize, communicate, and collaborate efficiently.

### Common Categories
- Word Processing
- Spreadsheets
- Presentation Software
- Database Software
- Collaboration Tools
