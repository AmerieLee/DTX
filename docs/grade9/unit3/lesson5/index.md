# Introduction

Computer networks continue to evolve. New technologies allow devices to communicate faster, smarter, and more securely than ever before.

This lesson explores technologies that are shaping the future of the Internet.

---

# Cloud Computing

Cloud computing allows users to store files and run applications on remote servers instead of a local computer.

Examples include:
- Google Drive
- Microsoft OneDrive
- Dropbox

Benefits:
- Access files anywhere
- Automatic backups
- Easy collaboration
- Reduced hardware costs

---

# Internet of Things (IoT)

The Internet of Things (IoT) is a network of physical devices connected to the Internet.

Examples:
- Smart watches
- Smart lights
- Smart speakers
- Smart home security cameras

IoT devices collect and share data automatically.

---

# Edge Computing

Instead of sending all data to distant cloud servers, edge computing processes some data close to where it is created.

Benefits:
- Faster response time
- Lower network traffic
- Better performance for real-time applications

---

# Artificial Intelligence in Networks

AI can help manage computer networks by:
- Detecting cyber attacks
- Predicting equipment failures
- Optimising network traffic
- Improving security

---

# 5G Networks

5G provides:
- Higher speeds
- Lower latency
- Support for millions of connected devices

Applications include autonomous vehicles, smart factories and remote healthcare.
