# What is Cybersecurity?

Cybersecurity is the practice of protecting computers, networks, programs, and data from attacks or unauthorised access.

Examples include:

- Unlocking a phone with biometrics
- Shopping online
- Internet banking
- Secure messaging
- School accounts

---

# Why Does Cybersecurity Matter?

Without cybersecurity, attackers may:

- Steal personal information
- Delete files
- Spread malware
- Lock computers with ransomware
- Steal money

---

# The CIA Triad

| Principle | Meaning |
|------------|---------|
| Confidentiality | Only authorised users can access data. |
| Integrity | Data cannot be changed without permission. |
| Availability | Data is available when needed. |

---

# Example

For a school grading system:

- Confidentiality → Only teachers can view grades.
- Integrity → Students cannot change grades.
- Availability → Teachers can access grades when needed.
