# Lesson 1 Teacher Notes – Introduction to the Web

## Duration
50–60 minutes

## Learning Objectives
- Distinguish the Internet from the World Wide Web.
- Explain browsers, web servers and URLs.
- Introduce the client-server model.

## Materials
- Slides
- Projector
- Internet access
- Student workbook

## Lesson Sequence
### Starter (10 min)
Discuss websites students use daily.

### Teaching (20 min)
Explain:
- Internet vs WWW
- Browser
- Web server
- URL
- Client-server communication

### Guided Practice (10 min)
Identify parts of example URLs.

### Independent Practice (10 min)
Complete workbook questions.

## Misconceptions
- Internet ≠ World Wide Web
- Browser ≠ Search engine

## Assessment
Questioning, workbook, quiz.

## Homework
Find three URLs and label protocol, domain and path.
