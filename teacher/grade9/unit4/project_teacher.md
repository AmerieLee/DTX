# Teacher Guide – Unit 4 Project
## Build Your Personal Website

## Project Overview
This project is the culminating task for Unit 4. Students apply HTML and CSS knowledge to build a multi-page personal website.

## Learning Outcomes
Students will:
- Create multiple HTML pages
- Apply an external CSS stylesheet
- Build working navigation
- Organise website files
- Evaluate and improve their work

## Suggested Schedule
| Lesson | Focus |
|---|---|
|1|Planning|
|2|HTML Development|
|3|CSS Styling|
|4|Testing & Improvement|
|5|Presentation|

## Teacher Preparation
- Confirm VS Code and browser are available.
- Provide starter folder if needed.
- Review relative file paths and external CSS.

## Assessment Focus
- HTML Structure
- CSS Styling
- Navigation
- Content
- Creativity
- Reflection

Refer to:
`projects/grade9/unit4/project_rubric.md`

## Common Mistakes
- Broken hyperlinks
- Incorrect image paths
- Missing closing tags
- Inline CSS instead of external stylesheet
- Inconsistent navigation

## Extension
- Responsive layout
- Dark mode
- CSS animation
- Gallery page

## Success Criteria
- Three or more webpages
- External CSS
- Working navigation
- Consistent design
- Clear explanation of design decisions
