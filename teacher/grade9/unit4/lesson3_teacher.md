# Lesson 3 Teacher Notes – Images and Hyperlinks

## Duration
50–60 minutes

## Learning Objectives
- Teach students to insert images with the `<img>` tag.
- Create hyperlinks using the `<a>` tag.
- Explain relative and absolute paths.
- Build a simple navigation menu.

## Lesson Sequence

### Starter (5–10 min)
Discuss why websites use images and navigation menus.

### Direct Instruction (20 min)
- `<img>` tag and attributes (`src`, `alt`, `width`, `height`)
- `<a>` tag and `href`
- Relative vs absolute paths
- Navigation menus

### Guided Practice (15 min)
Students create two HTML pages connected with hyperlinks and add one image.

### Independent Practice (10 min)
Students build a simple navigation bar linking Home, About and Contact pages.

## Common Misconceptions
- Images require a correct file path.
- `alt` text is important for accessibility.
- Relative paths depend on folder structure.

## Assessment
- Check hyperlinks work correctly.
- Verify images display.
- Review workbook and quiz responses.

## Extension
Add links to external websites and create a three-page website.

## Homework
Create a personal homepage with one image and links to two additional pages.
