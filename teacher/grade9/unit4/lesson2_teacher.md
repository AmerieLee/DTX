# Lesson 2 Teacher Notes – Basic HTML

## Duration
50–60 minutes

## Learning Objectives
- Explain the purpose of HTML.
- Introduce the basic HTML document structure.
- Demonstrate headings, paragraphs and lists.
- Guide students to create their first web page.

## Lesson Sequence

### Starter (5–10 min)
Ask:
- Have you ever viewed the source code of a web page?
- What do you think HTML does?

### Direct Instruction (20 min)
Cover:
- HTML overview
- Document structure
- `<html>`, `<head>`, `<title>`, `<body>`
- `<h1>`–`<h6>`
- `<p>`
- `<ul>`, `<ol>`, `<li>`

### Guided Practice (15 min)
Students create:
- One heading
- Two paragraphs
- One unordered list

### Independent Practice (10 min)
Students personalise their page with their own content.

## Common Misconceptions
- HTML is not a programming language.
- Browsers ignore most whitespace.
- Tags usually come in opening and closing pairs.

## Assessment
- Observe practical work.
- Check HTML structure.
- Review workbook activities.

## Extension
Students add another heading and an ordered list.

## Homework
Create a simple "About Me" web page using the tags learned today.
