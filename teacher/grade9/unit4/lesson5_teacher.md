# Lesson 5 Teacher Notes – Building a Complete Website

## Duration
50–60 minutes

## Learning Objectives
- Integrate HTML and CSS into a complete website.
- Organise files using a clear folder structure.
- Test hyperlinks and images.
- Evaluate website usability.

## Lesson Flow

### Starter (5 min)
Review HTML and CSS concepts.

### Demonstration (15 min)
Build a simple three-page website.

### Guided Practice (20 min)
Students create:
- Home page
- About page
- Contact page
- External stylesheet

### Independent Practice (15 min)
Students test navigation, images and layout.

## Assessment
- Correct folder structure
- Working navigation
- Consistent CSS
- Clear page layout

## Extension
Add a gallery page or FAQ page.

## Homework
Improve the website by adding additional content and styling.
