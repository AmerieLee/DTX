# Teacher Guide – Unit 5 Lesson 1
## Introduction to Productivity Tools

## Lesson Overview
Students explore the purpose of productivity tools and identify common categories of software used in school and the workplace.

## Learning Objectives
Students will be able to:
- Define productivity tools.
- Classify common productivity software.
- Explain how productivity applications improve efficiency.
- Identify appropriate software for different tasks.

## Key Vocabulary
- Productivity
- Word Processor
- Spreadsheet
- Presentation
- Database
- Collaboration
- Cloud Storage

## Materials
- Computer with Internet access
- Presentation slides
- Student worksheet
- Whiteboard

## Lesson Sequence

### Starter (10 min)
Ask students:
- Which applications do you use every day?
- Which software helps you complete homework faster?

### Direct Instruction (15 min)
Introduce:
- Definition of productivity tools
- Main software categories
- Real-world examples

### Guided Practice (15 min)
Students classify software into categories and discuss suitable uses.

### Independent Activity (15 min)
Students complete a comparison table and explain which application they would choose for different scenarios.

### Plenary (5 min)
Exit ticket:
"Describe one way productivity tools improve teamwork."

## Differentiation
Support:
- Provide software icons and examples.
Extension:
- Compare desktop and cloud-based productivity tools.

## Assessment
Observe participation, review completed tables, and evaluate exit tickets.

## Homework
Research one productivity application and describe three features.
