# Design a School Network

## Project Overview

**Role:** ICT Network Consultant

Your team has been hired to design the computer network for a new school building. Create a reliable, secure, and cost-effective network that supports students, teachers, and administrators.

---

## Learning Goals

- Apply networking concepts from Unit 3.
- Select appropriate networking devices.
- Design a logical network topology.
- Consider security and future expansion.
- Present technical ideas clearly.

---

## Project Tasks

### Task 1 – Analyse Requirements
Identify:
- Classrooms
- Computer labs
- Library
- Office
- Wi-Fi coverage
- Internet access needs

### Task 2 – Select Equipment
Choose suitable:
- Router
- Switches
- Wireless Access Points
- Servers
- Desktop PCs
- Printers

Explain why each device is needed.

### Task 3 – Design the Network
Create a labelled network diagram showing how devices are connected.

### Task 4 – Security Plan
Include at least four security measures such as:
- Strong passwords
- Firewall
- Antivirus
- Regular backups
- Guest Wi-Fi

### Task 5 – Budget
Estimate equipment costs using the provided budget template.

### Task 6 – Presentation
Prepare a 5–7 minute presentation explaining your design choices.

---

## Deliverables

- Network diagram
- Equipment list
- Budget
- Security plan
- Presentation slides
- Individual reflection

---

## Success Criteria

Your project should:
- Meet the school's requirements
- Be logically organised
- Use correct networking terminology
- Demonstrate good security practices
- Be clearly presented

---

## Extension Challenge

How could your network be upgraded in the future to support AI, IoT devices, or smart classrooms?
