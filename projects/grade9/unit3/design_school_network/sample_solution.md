# Sample Solution
## Grade 9 ICT – Unit 3 Project
### Design a School Network

> This is an example solution. Student answers may vary.

## School Requirements
- 20 Classrooms
- 2 Computer Labs
- Library
- Administration Office
- Staff Room
- Whole-campus Wi-Fi

## Recommended Equipment

| Device | Qty | Purpose |
|---|---:|---|
| Router | 1 | Connect school to ISP |
| Core Switch | 2 | Connect network segments |
| Access Switch | 8 | Classroom connections |
| Wireless Access Point | 18 | Campus Wi-Fi |
| Server | 2 | File and authentication |
| Network Printer | 4 | Shared printing |

## Security Plan
1. Strong passwords and MFA for staff.
2. Firewall between Internet and school network.
3. Separate Guest Wi-Fi.
4. Automatic daily backups.
5. Antivirus on all computers.
