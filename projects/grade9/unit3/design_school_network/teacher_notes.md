# Teacher Notes
## Grade 9 ICT – Unit 3 Project
### Design a School Network

## Project Overview
Students work in teams as ICT consultants to design a secure, reliable, and cost-effective network for a new school building.

**Duration:** 4–6 lessons

## Learning Outcomes
- Apply networking concepts from Unit 3.
- Select suitable networking devices.
- Create a logical network diagram.
- Justify design decisions.
- Develop a basic cybersecurity plan.
- Present solutions professionally.

## Suggested Timeline
### Lesson 1
- Introduce the scenario
- Form teams
- Analyse school requirements

### Lesson 2
- Select networking devices
- Begin network diagram

### Lesson 3
- Complete topology
- Develop security plan
- Estimate budget

### Lesson 4
- Prepare presentation
- Teacher conferencing

### Lesson 5
- Team presentations
- Peer evaluation
- Reflection

## Materials
- Project brief
- Worksheet
- Budget template
- Network symbols
- Internet access
- Presentation software

## Teacher Tips
- Encourage multiple valid solutions.
- Ask students to justify every device they select.
- Remind students to balance performance and cost.
- Check that security is considered from the beginning.

## Common Misconceptions
- More devices always make a better network.
- Wi-Fi alone is sufficient for every room.
- One password is acceptable for everyone.
- Backups are optional.

## Formative Assessment
Monitor:
- Team collaboration
- Planning
- Device selection
- Network diagram accuracy
- Security planning

## Differentiation
Support:
- Provide a partially completed diagram.
- Offer a device reference sheet.

Extension:
- Add VLANs.
- Include IoT classrooms.
- Plan for future expansion.

## Presentation Checklist
Teams should explain:
- Requirements
- Device choices
- Network topology
- Security measures
- Budget
- Future improvements

## Reflection
After presentations, discuss:
- What worked well?
- What would you improve?
- How could AI help manage this network?
