# Unit 4 Project – Build Your Personal Website

## Project Overview

In this project, you will apply everything you learned in Unit 4 by designing and building a small multi-page website using HTML and CSS.

This project provides an opportunity to demonstrate your understanding of webpage structure, CSS styling, navigation, and good web design principles. Your final website should be attractive, easy to navigate, and suitable for a real audience.

---

# Learning Objectives

By completing this project, you will be able to:

- Create a complete website using HTML.
- Apply CSS to improve appearance.
- Organize files using an appropriate folder structure.
- Create navigation between pages.
- Insert images and hyperlinks correctly.
- Test and improve your website.
- Apply basic web design principles.

---

# Essential Question

**How can a well-designed website communicate information effectively while providing an enjoyable user experience?**

---

# Project Scenario

Imagine you have been asked to create your own personal website to introduce yourself to classmates, teachers, and future employers.

Your website should present information in a clear, attractive, and professional manner while demonstrating your HTML and CSS skills.

---

# Project Requirements

Your website must include:

## Required Pages

- Home (index.html)
- About Me
- Contact

## Required Features

- Navigation menu on every page
- External CSS stylesheet
- At least one image
- Headings and paragraphs
- Lists or tables
- Working hyperlinks
- Consistent colour scheme
- Appropriate fonts
- Page titles

---

# Suggested Folder Structure

```text
website/
├── index.html
├── about.html
├── contact.html
├── style.css
└── images/
```

---

# Design Guidelines

Your website should demonstrate good web design by following these principles:

- Keep pages simple and easy to read.
- Use consistent colours and fonts.
- Leave enough white space.
- Align text and images neatly.
- Make navigation easy to understand.
- Avoid excessive colours or animations.

---

# Recommended Development Process

### Step 1 — Plan

Sketch each webpage before coding.

### Step 2 — Build HTML

Create the page structure and content.

### Step 3 — Apply CSS

Improve the appearance using an external stylesheet.

### Step 4 — Test

Check:

- spelling
- navigation
- images
- hyperlinks
- page layout

### Step 5 — Improve

Fix errors and make the design more attractive.

# Common Mistakes to Avoid

- Missing closing tags
- Incorrect file names
- Broken image paths
- Broken hyperlinks
- Inline CSS instead of external CSS
- Inconsistent fonts or colours
- Poor spacing and alignment
