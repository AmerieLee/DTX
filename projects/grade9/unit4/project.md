
# Unit 4 Project – Build Your Personal Website

## Project Overview

In this project, you will apply everything you learned in Unit 4 by designing and building a small multi-page website using HTML and CSS.

---

## Learning Objectives

By completing this project, you will be able to:

- Create a complete website using HTML.
- Apply CSS to improve appearance.
- Organize files using an appropriate folder structure.
- Create navigation between pages.
- Test and improve your website.

---

## Project Requirements

Your website must include:

### Required Pages
- Home (index.html)
- About Me
- Contact

### Required Features
- Navigation menu on every page
- External CSS stylesheet
- At least one image
- Headings and paragraphs
- Lists or tables
- Working hyperlinks

---

## Suggested Folder Structure

```
website/
├── index.html
├── about.html
├── contact.html
├── style.css
└── images/
```

---

## Extension Challenge

Choose one or more:

- Gallery page
- Hobbies page
- School page
- Favourite books or movies
- Responsive improvements

---

## Submission Checklist

- [ ] Three or more webpages
- [ ] External CSS file
- [ ] Images displayed correctly
- [ ] Navigation works
- [ ] No broken links
- [ ] Clean and consistent design
