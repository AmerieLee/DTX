# Unit 4 Project Assessment Rubric

**Project:** Build Your Personal Website

---

## Project Goal

Students will design and build a multi-page personal website using HTML and CSS. The project assesses students' understanding of web page structure, styling, navigation, organization, and design principles.

---

# Assessment Rubric (30 Marks)

| Criteria | Excellent | Good | Satisfactory | Needs Improvement | Marks |
|----------|-----------|------|--------------|-------------------|------:|
| **HTML Structure** | Uses correct HTML structure throughout. Semantic elements are used appropriately with no errors. | Mostly correct HTML with only minor errors. | Basic HTML structure is present but contains several errors. | HTML structure is incomplete or incorrect. | **6** |
| **CSS Styling** | Effective and consistent styling with attractive layout, colours, spacing, and typography. | Good styling with only minor inconsistencies. | Basic styling applied but lacks consistency. | Little or no CSS styling. | **6** |
| **Navigation & Hyperlinks** | Navigation menu works perfectly on every page. All links function correctly. | Minor navigation issues. | Some links work but navigation is inconsistent. | Navigation is missing or many links are broken. | **5** |
| **Content & Organization** | Content is complete, well-organized, and easy to understand. All required pages are included. | Content is mostly complete and organized. | Some required content is missing or poorly organized. | Major sections are missing or incomplete. | **5** |
| **Creativity & Visual Design** | Creative design with excellent visual appeal and effective use of images. | Attractive design with some creative features. | Simple but acceptable design. | Minimal effort shown in presentation. | **4** |
| **Reflection & Documentation** | Reflection demonstrates thoughtful evaluation and identifies realistic improvements. | Good reflection with clear ideas. | Basic reflection completed. | Reflection missing or incomplete. | **4** |

# Teacher Feedback

## Strengths

- Excellent HTML structure
- Effective use of CSS
- Clear navigation
- Attractive visual design
- Well-organized content

## Areas for Improvement

- Improve code organisation and readability.
- Maintain consistent styling across all pages.
- Add more meaningful content.
- Improve accessibility and usability.
- Check all hyperlinks before submission.
